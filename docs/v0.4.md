# v0.4 release notes

[简体中文](zh-CN/v0.4.md) · [Home](../README.md)

v0.4 added stable upload/review references, committed-state recovery, queue admission
limits, source-freshness labels, optional backup coverage for unreviewed uploads,
and English confirmation phrases.

The base setup remains Python and Git with three stdio MCP tools. Team mode requires
exact Owner confirmation. Personal mode is an explicit policy for low-risk preferences.
Neither an upgrade nor a recall enables snapshots, cloud sync or automatic cleanup.

v0.4 does not include the complete upload cleanup lifecycle. For project-scoped request
identity, same-text evidence updates, effective-result backfill and queue maintenance,
use [v0.5](v0.5.md) and its [operations guide](maintenance.md).

Older release tags preserve their original code. Real memory, pending inputs and
private configuration belong in a separate local store, never this public repository.
