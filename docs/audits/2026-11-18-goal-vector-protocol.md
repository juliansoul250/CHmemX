# 检索目标向量复核实验：预注册

目的：判断理解计划的 `goal` 与已入选记忆正文块的最大余弦相似度，能否排掉主题相关、字段不支持的候选。相似度不是事实核验。本实验不使用答案生成、外部模型、新索引或词表。不在旧 160 题上选择参数。

- 两个分别创作的新合成集合：开发 / 留出各 16 条虚构记忆、48 个中英文问题，领域不重叠。每集直接 12、改写 8、多意图 8、条件 4、无答案 16；问题规划者只接触问题。所有新样本均为全局记忆。Scope、过期和权限继续由现有测试守护。不是生产随机样本。
- 对照：工作区当前 planned hybrid Top-3，关联预算 0。候选只对原来可召回的单意图搜索结果做必要条件过滤，不扩展候选，不更改项目路由。显式原题记录 key 保留。缺模型、超窗、含分面、非搜索决策不改变。候选最多额外编码一个目标，用同一锁定模型、相同正文片段。阈值仅试 `dense_minimum - dense_window`, `dense_minimum`, `dense_minimum + dense_window`（本索引 0.42、0.50、0.58）。
- 主指标：完整支持（正例全部必需记录且无禁用，负例空返回）；分报正例完整、多意图完整、无答案误返回、严格集合、命中率。延迟需区分新增编码与正文读取，规划耗时不计。
- 选择：开发集完整支持提高、无答案误返回严格减少、正例和多意图完整数不降、严格集合数不降、运行错误为零，才具有入选资格。合格时按完整支持、严格集合、较低阈值择一。无合格项则保留原方案；仅将完整支持、严格集合、较低阈值依次最优的实验项锁定为对照诊断，不转为产品候选。
- 先写入不可覆写的选择记录及开发/留出输入、实现哈希，后首次运行留出。留出同门槛，不通过不改默认。另测旧 160 题 planned Top-3，同样不接受正例完整、多意图完整、严格集合或无答案拒绝的倒退。历史非盲题只作回归；不改 gold、验证阈值和旧分面。
- 产物：逐题配对结果、公开可重放的合成数据与实验代码、聚合结论。新数据不入真实记忆；无上线、交接或凭据读取。若证据不支持改动，报告否决结果，不把实验最佳分数当作改进。
