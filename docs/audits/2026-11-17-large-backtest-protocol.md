# 扩大回测预注册口径 · 2026-11-17

目的：判断当前检索准确性，不在本轮修复、调参、改标签、改提示词追分。Owner 已取消记忆交接；本轮不提交/交接记忆、不发布服务或线上索引。

## 冻结与隔离

- 当前实现、配置和既有文件先做 SHA-256 冻结；结束再次核对。
- 两个独立作者分别构建工程运维、公务文化服务领域的 32 条虚构记忆、80 个不同问题。合计目标 64 条记忆、160 个新问题，中英文、两个项目与全局范围。
- 每组问题配额：直接 16、改述 16、多意图 16、限定条件 8、无答案 16、歧义 8。改述不得只是直接题的重复表达；仍按主题聚类，不能把共享事实的问题当完全独立样本。
- 作者不知道检索实现或旧错题；题目/事实/标签在检索前冻结。另一 Agent 仅看不含标签的问题文件，生成理解计划。
- 独立标签审阅在看到检索结果之前完成。保留全部原始标签；被审阅指出的争议题只做单列敏感性分析，不悄悄删除或重新标注。
- 全部合成记忆经一次性测试库的正常提议、批次、审核、批准接口建立；不接触线上 Active。范围来源只使用本次生成的测试 Git 仓库。

## 比较与样本计数

- 同一混合索引、同一问题和标签比较字面兼容检索与独立理解计划检索。
- K=3 是主比较；K=1、5 为事先指定的敏感性分析，不能挑最好 K 作为主结论。
- 同时报告 K=3 词法消融，以及“总是 search、无子查询”的单查询计划对照：后者不是理解模型，只用于分离公共范围门禁与真正问题规划的影响。共 9 个固定配置，目标 1,440 次新集查询执行，但只计 160 个新问题，不能宣称 1,440 个独立问题。
- 原历史 162 正例+10 噪声、旧合成43条、上一轮12条理解试验分开重跑，不混入新集准确率。
- 记录接口错误、无效计划、缺答案、额外不相关项、项目越界、扫描与编码窗口预算；错误不从分母移除。

## 指标

1. **完整支持召回率**：所有标注必需记录都返回，且无明确禁用记录；不代表多余记录都相关。
2. **精确集合通过率**：返回集合与全部支持标签完全一致；空答必须确实无候选，而非接口报错。
3. 正例 Hit@1、Hit@K、MRR、相关记录 Recall@K、返回结果 Precision；无结果的正例 Precision 记 0，不能通过空答提高精度。
4. 无答案正确拒答率与误召回率；歧义空结果与 clarify 动作分别统计。清晰但库内无答案的问题，不预先教规划器拒绝检索。
5. 按领域、语言、场景、项目分层，不只报一个总体数。
6. Wilson 95% 区间描述二项比例的不确定性；主题簇 bootstrap 95% 区间评估相关样本与成对差异，固定随机种子与重采样次数。它们不消除合成分布和机器标签偏差，不能外推为真实用户总体准确率。

## 结论边界

此次测量的是候选检索，不是生成答案的事实正确率。独立 Agent 不是人类盲标者；同供应商模型可能共享偏差。无真正用户问句抽样，不能声称生产准确率。延迟记录仅作诊断，包含校验但不包括理解模型生成计划时间，不承诺性能改善。
