# 轮流找回与主题目录：对照协议（先于新留出结果）

本次检验两个不同问题：追问缺失证据能否多找回记录；改变主题分组能否改善同一查询的结果。**两种收益分别记账。** 不修改真实库、模型、召回门槛、审批或权限。所有数据为虚构；不用问题、标准答案、Agent 的引文或重试记录生成树的关键词。

## Agent 轮次

三位独立 Agent 按顺序在原有基准树上实际调用检索器，每人处理开发档案中按原顺序取出的前 12 题。第 1 轮使用原计划；后两轮可见上一轮问题、计划、候选及逐项缺口，但不可见标签或库中其他正文。可以为真实缺口改写分面；原查询、实体与条件不能删除或换值，不得猜答案或搜候选 ID。每轮 K=3，关联预算 0。仅以本轮返回正文中的逐字原句判断 `supported / partial / insufficient`。分别报告每轮结果、累计分析上限、实际调用数与额外读取；不能把累计 9 个候选的结果说成单轮 Top-3。引文存在不等于语义支持；回测另对照预先冻结的记录标签。

## 一次性树对照

1. **基线**：项目 + 规范键上级前缀的原目录。固定 K=3、关联预算 0、同一调用方理解计划、模型锁、正文、查询和来源检查。
2. **关闭目录分组**：关闭 cell 分数及其对 node 的加分，不动节点、正文/键、IDF、BM25 或正文稠密向量。区分目录贡献与节点关键词贡献。
3. **关闭显式导航特征**：在 2 的基础上，关闭节点、关系、节点标题/别名/关键词及 hint 的计分与词法匹配。重建不含这些特征的记录稀疏向量，仍用基线 IDF；保留正文、键、类别、来源定位、BM25、稠密向量和原查询范围。此对照不等同重新训练完全无导航词的模型。
4. **候选树**：项目及键前缀仍是上界，只将同一前缀内确实被多条记录共享、又不覆盖整个前缀的已批准节点作为叶子。标题、关键词、别名只来自节点本身。相同成员集合去重；没有适用共享节点则保留原分组，未覆盖的记录留在前缀桶中。无需新同义词表。不更改正文或节点本身；重建派生目录会连带更新其语料 IDF，如实计入候选效果。

在旧 160 题和旧开发/留出各 48 题作回归；新独立作者写 12 条新记录（4 个有已批准共享节点的主题）、24 道中英文未见题，由另一位仅看问题的 Agent 规划。旧题不作为新的独立验证。四组均跑同一批，失败保留在分母。核心指标：完整支持、严格集合、有答案完整、多意图完整、无答案误返回、范围违规及出错；另报候选顺序变化。新 24 题是小样本，不能推断生产准确率。

**判定预先固定**：新留出完整支持严格增加，正例、多意图、严格集合不下降，无答案误返回不增加；旧组完整支持、正例及多意图均不降；零范围违规、零执行错误，才考虑将分组策略设为默认，否则只交付可复现的离线候选和实测差异，不按错题继续改词。独立的结构性错误（例如系统生成的全局分组混入同名项目键）先用回归测试复现，可在不改变公开召回边界的前提下修复；不把修复算成准确率提升。
