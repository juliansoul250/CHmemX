# 大样本检索回测：理解有帮助，当前仍不够可靠

日期：2026-11-17。状态：**回测完成；不是发布验收通过。** 对象为当前工作区候选实现，不是线上版本替换后的实测。

本轮仅测量，不修代码、不调阈值、不改标签、不交接记忆。冻结的 130 个既有项目文件逐字节未变；线上记忆、索引及模型未发布或替换。

## 1. 规模与隔离

- 新增 **160 个不同问题**，不是 1,440 个独立问题；中文、英文各 80。
- 64 条虚构记忆，两个领域：工程工作规程、文化与社区事务；48 条全局、各 8 条属于 north/south 项目。
- 112 个有支持记录的问题、32 个无答案问题、16 个含糊问题；共 17 个标注主题簇。
- 每题执行 9 个配置，共 **1,440 次检索**：混合检索原句/理解计划各 K=1/3/5；词法原句/理解计划各 K=3；混合单查询计划控制组 K=3。
- 两个独立作者生成事实与题目；两个规划者只看问题，不看记忆、答案、实现或旧回测。原生会话工具记录核验：规划者仅读取指令、问题和自己的输出。
- 独立标签审阅在首次新题检索之前完成；发现的争议保留原标签，单列敏感性分析。
- 记忆通过真实 API 写入一次性 Git 测试仓库，查询开启来源检查；使用已有本地模型，不下载或替换模型。
- 本轮图关联预算固定为 0，测主检索及多查询，不冒充新的多跳图推理测试。

现有 162 个真实历史正例、10 个历史噪声例、43 个旧合成例和此前 12 例也复跑。它们已参与过开发，独立列作回归，不能与新题相加宣称同等独立样本。

## 2. 主结果：混合检索，Top-3

**完整支持通过**：正例找齐全部标注记录且没有禁用项；负例必须无结果。允许额外非禁用记录，因此不等于全部正确。

**严格集合通过**：不漏、不多取、不含禁用项。以上均为候选检索指标，不是生成答案正确率。

| 指标 | 原句检索 | 理解后检索 |
| --- | ---: | ---: |
| 完整支持通过 | 84/160，52.50% | **106/160，66.25%** |
| 严格集合通过 | 68/160，42.50% | **85/160，53.13%** |
| 正例找齐且无禁用项 | 72/112，64.29% | 83/112，74.11% |
| 正例至少命中一条，Hit@3 | 85.71% | 90.18% |
| 正例平均 Recall@3 | 75.89% | 83.04% |
| 正例平均 Precision@3 | 73.66% | 75.45% |
| 负例正确空返回 | 12/48，25.00% | 23/48，47.92% |

不能用 **90.18% Hit@3** 宣称系统准确率超过 90%：找到一条相关记忆，可能仍漏掉其他必需事实，或夹带不适用规则。

配对比较：新增 22 个完整支持通过，原来通过的新集题目没有退化。理解后主指标 Wilson 95% 区间 **58.62%–73.12%**；按主题簇重采样的区间 **60.36%–72.51%**。配对增益 +13.75 个百分点，主题簇 bootstrap 95% 区间 **+8.78 至 +18.06 个百分点**。

这些区间仅描述本合成题集的变动，不覆盖真实用户分布、作者风格或模型家族偏差。

## 3. 改善来自哪里

- 多意图完整支持：**5/32 提升至 15/32**。
- 含糊问题正确空返回：4/16 提升至 15/16。另核对实际状态：理解组 **15 次 `NEEDS_CLARIFICATION`**；不是把空结果直接算作澄清动作。
- 直接问题：29/32 提升至 30/32。
- 改写问题 28/32、条件问题 10/16、无答案正确拒绝 8/32，**均未改善**。

总计 +22：10 来自多意图、11 来自含糊问题、1 来自直接问题。不能把全部收益归因于向量排序变强。

同样走严格计划接口，但永远搜索、不拆分、不澄清的控制组为 **86/160，53.75%**。理解组高出 20 题；其中多意图和含糊问题各贡献 10 题。支持“规划整体有益”，不单独证明每个分面都理解正确。

## 4. 失效位置

理解组 Top-3：

- **无答案问题：24/32 仍返回记忆，误返回率 75%。**
- 多意图：17/32 未找齐全部支持。
- 条件问题：6/16 未通过。
- 全部正例：2 题空返回、27 题部分命中/错误/含禁用项；另有 21 题虽然找齐，却多取无关记录。
- 原始标签下共 54 题未通过完整支持，75 题未通过严格集合；运行错误 0。

代表性例子均来自新增虚构题集，未用于补丁或调参：

1. `a-q057` 问“共享纸模标签打印机，每张标签收取多少打印费？”返回打印机管理与分包规则，但记录没有价格。规划目标已正确写成“查找每张标签打印费”，结果仍标记 `answer_support: not_assessed`。**理解问题不等于验证记忆足以回答。**
2. `a-q035` 同问坐标框、预览格式与比例，三个查询都只找到了坐标框记录，漏掉另一条英文预览记录。独立诊断中，遗漏记录余弦分数分别为 0.3423、0.3063、0.3179，低于现有 0.50 门槛；两个分面重复完整原题再加“重点查…”提示。已确认未形成有效互补；究竟应改善分面、跨语言实体匹配还是编码器，需要新开发集检验，不能据此补答案关键词。
3. `a-q049` 明确询问 north 非样品批次，返回正确项目规则，同时夹带禁用的泛化标签规则。项目范围内合法并不代表规则条件适用。

主指标中文 **51/80，63.75%**，英文 **55/80，68.75%**；两领域分别 51/80、55/80。分组样本有限，不能据此确定语言能力差异。

## 5. 加大 K 与词法对照

- 理解组完整支持：K=1 **53.13%**，K=3 **66.25%**，K=5 **66.88%**。
- K=3 增至 5 只多通过 1 题；严格集合仍为 53.13%，无答案拒绝不改善。仅扩大返回数不是主要解法。
- 词法 Top-3：原句 41.25%，理解组 43.75%；混合理解组 66.25%。语义通道重要，但不能替代答案支持检验。

全部 1,440 次执行中重复正文读取 0，单次最大正文读取 5。理解组及单查询计划控制组，超出原题允许项目范围的返回均为 0。兼容原句主配置有 2 题触发原有跨项目参考行为；这是兼容策略差异，不作为已证明的权限漏洞。

不报告端到端规划速度：本次规划耗时未计入逐次检索耗时，也未建立性能采样目标。

## 6. 标签争议与统计限制

首次运行前，独立审阅标记 7 题。最明显的 `a-q080` 有可用条件规则，却标为空答案；`a-q077`、`a-q079` 将“条件未明确、需澄清”与“不能检索该政策”混为一谈。其他 4 题存在不充分前提。原标签未改：

- 全 160 题：52.50% 对 66.25%。
- 只排除最强争议 1 题：52.83% 对 66.67%。
- 排除 3 个含糊支持争议：53.50% 对 66.24%。
- 排除全部 7 题：**52.94% 对 65.36%**。

增益方向未反转，但通过率仍是给定标签下的结果。17 个主题簇共享 64 条记忆；跨主题、同一作者的相关性未完全消除。两个领域和同一家族 Agent 作者不能代表生产流量；这不是人工盲标生产测评。

## 7. 旧回归与核验

- 旧 162 正例 + 10 噪声、43 合成例：修改前后输出与指标全部一致。
- 历史混合检索仍有 6 个未通过案例，其中 1 个是互相矛盾的关联标签；不能宣称历史门禁全绿。
- 旧合成混合检索 41/43；此前 12 例原句 8/12、独立理解计划 9/12，均未变。
- 新统计器 7 个测试通过；与旧 12 例逐项交叉核对一致。
- 独立算术复核全部 1,440 条结果；冻结输入哈希、争议记录先于执行的时间戳及 130 个既有文件均校验通过。
- 另做独立统计审查：未发现阻断性算术缺陷；要求区分检索/澄清、标签正确性与生产推广范围，已落实。

## 8. 判断与后续边界

**先理解再检索确有收益，但当前还不是可靠的记忆问答系统。** 最突出的问题不是“没找到相似内容”，而是未验证所问字段有没有证据、多意图是否齐全、返回规则的条件是否适用；同时仍有跨语言候选漏召回。

下一阶段应在独立开发集上研究证据充分性与条件匹配，再用另一套未看过的题验收。不可继续针对本 160 题改同义词、阈值或标准答案，也不可把返回更多记忆当作准确性改善。本轮保持实现冻结，不做这些修改。
