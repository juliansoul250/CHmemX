# v0.4 版本说明

[English](../v0.4.md) · [首页](../../README.zh-CN.md)

v0.4 增加了稳定上传编号、审阅重试、提交状态恢复、队列限额、来源时效标记、未审上传的可选备份，以及英文确认文本。

基础运行仍只需 Python 和 Git，MCP 保持三个工具。团队模式需要 Owner 精确确认；个人模式仅在明确开启后处理低风险偏好。升级和查询都不会自动开启快照、云同步或清理。

v0.4 尚无完整的上传回收流程。项目隔离的请求身份、同文证据更新、有效召回补位和队列维护，请使用 [v0.5](v0.5.md)，并阅读[维护指南](maintenance.md)。

旧版本标签保留原代码。真实记忆、待审输入和私人配置应留在独立本地仓库，不进入公开工具仓库。
