# v0.3 修改判断与验收

[English](../v0.3.md)

这次优先解决接入和日常操作成本。基础 MCP 不加数据库、服务端口或模型依赖；
高级功能按需要开启。仓库关注度低的原因没有足够数据，不能归因给某一个缺失功能。

| 建议 | 处理方式 |
|---|---|
| start / recall / upload MCP | 已实现，并用官方 MCP 客户端实测 |
| 所有无冲突项自动合并 | 收窄：团队模式不变，单人模式显式开启，只放行受限低风险新增项 |
| 精确重复 | 只返回已有 ID、记审计事件，不再建候选或提交 |
| 本地稠密向量与 RRF | 可选；词法高置信结果优先，词法拒答时再融合补召回 |
| Ed25519 | 可选；固定来源公钥、过期和重放检查，不把签名当安全证明 |
| 禁止指令式记忆 | 只做有界字符串、命名空间和可疑结构检查；不声称完整识别自然语言指令 |
| 召回隔离 | API 固定返回“不可信历史数据”声明及来源；不是模型沙箱 |
| 声誉与行为信号 | 先做来源事件统计、连续冲突升级审查；不靠高声誉放宽权限 |
| 按来源一键回滚 | 改为先审阅停用计划，只停用该来源当前生效项，保留他人的后续修正 |
| 增量索引与文件监听 | 复用正文/模型摘要相同的嵌入；全局 IDF 仍重算；文件监听暂缓 |
| 自动生成金标 | 只作回归覆盖；独立问法另设冻结集，不按输出改答案 |
| Windows | 加入原生锁分支；完整 Windows 验收尚未完成 |

## 向量效果

下表来自一套私有本地语料：90 条记忆、84 个索引节点。公开仓库只保留统计，
不包含真实记忆、问题或机器路径。这是有限样本，不是通用能力保证。

| 检查 | 旧索引 | 新候选 |
|---|---:|---:|
| 既有回归 | 136/136 | 136/136 |
| 图谱关联 | 5/5 | 5/5 |
| 32 条开发集换说法，Hit@3 | 7/32 | 24/32 |
| 24 条独立保留问题，Hit@3 | 5/24 | 19/24 |
| 22 条无关查询正确返回空 | 22/22 | 22/22 |
| 本次检查的越界或禁止项命中 | 0 | 0 |

24 条保留问题在实现前冻结，第一次运行命中 19 条。之后把显示元数据和排序特征分离，
修复两条旧回归的首位排序；再次运行仍为 19 条。这次重跑只是确认，不能再叫盲测。
没有修改保留集答案或给失败问题补提示词。仍有 5 条漏召回或错召回。
32 条开发集用于过迭代，不能拿它证明泛化。

直接把所有通道 RRF 混排，曾让旧集 Top-1 降到约 83%，因此没有采用。
现在保留词法强匹配，只有词法不返回时才用语义补充。代价是：错误但高分的词法结果
仍可能挡住正确语义结果。阈值不是准确率概率。

本机 90 条语料热查询 P50 约 128ms、P95 约 134ms，模型冷启动约 740ms。
一个虚构偏好的机械流程测得：策展到密封审阅约 28ms、提交约 97ms、提交到首次可召回约 289ms。
人工确认耗时没有测量，不能用机器耗时冒充。小样本写入时延也不能代表完整语料重建。
174 个未变化的嵌入块可按摘要复用，但索引元数据与 IDF 仍需重算。

## 安全边界

签名证明某个固定公钥对应的私钥签过这些字节，不证明内容善意，也不证明引用真由 Owner 发出。
注册了公钥的来源不能通过省略签名降级。未注册的本地身份仍是软身份，同一系统用户可以改文件。

直接封禁“执行”会误伤合法偏好，也挡不住换个说法的恶意文本。因此可疑角色/覆盖结构进隔离区，
敏感动作走审查，但这是启发式检查，不是可靠的恶意识别器。单人模式仍可能自动接受伪装成事实的错误内容。

召回端的声明不能强制模型把文本设为“低权重”。消费 Agent 必须把记忆作为数据，
不能放进系统指令，也不能让记忆授权工具执行、外发数据或提升权限。
高接受率不增加来源权限；召回分布变化只提示复查，不能直接断言受到了污染。

按来源停用先绑定 HEAD 和目标清单。它不删除历史、不覆盖其他来源后来确认的修正；
提交失败只恢复本次触及的文件。Git 不是异地备份，本次也不自动备份、清理或同步。

## 升级不会做什么

不会替已有团队仓库开启自动批准；不会把私有记忆推送 GitHub；不会自动下载模型。
原 CLI 保留，新 MCP 走 v3 的正文哈希与 Active 成员校验。旧脚本直接调用者需切到新入口
才能获得新增读保护。发布源码与切换正式索引是两件事。

完整参数见 [MCP 使用](mcp.md)，模型与冻结评测见[语义检索](../semantic.md)。
