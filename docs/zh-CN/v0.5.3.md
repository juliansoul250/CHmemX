# v0.5.3：身份检查与历史长正文修正

[English](../v0.5.3.md)

本版正式发布此前 main 上的两项修复。旧 v0.5.2 标签不移动；按旧标签安装不会获得本次修复。

- 精确身份和别名检查使用完整、已校验的定义集，不再依赖子串搜索的分页结果。展示仍分页，别名仍进入审阅，不自动合并。
- 合法旧长记录可以接受短修正。新上传仍限制 8192 字符，旧版 512 KiB 上限、冲突审阅、Owner 精确确认和替代历史不变。
- 回归覆盖补充项目 decision/evidence 的来源、修正、批准与召回全链路，以及标准 MCP SDK 的大冲突响应和重连。

## 本地升级

将 v0.5.3 安装到工具现有或独立验证过的环境，再重连对应客户端的 MCP 进程。核对实际安装版本和握手版本；只更新源码目录不代表所有客户端都已更新。

保留现有记忆目录、政策、待审包和索引配置。从 v0.5.2 升级不需要初始化或迁移记忆；更早版本及自定义适配层须另行检查兼容性。安装本版不自动开启 Personal、不改变批准方式、不重建用户索引，也不授权新的 Active 写入。客户端验收完成前保留旧运行时，以便回退。

## 大响应边界

历史冲突响应包含完整 current 和 diff，可能超过 1 MiB。SDK 回归验证了完整数据与重连后的同一请求身份，不要求 JSON 字段顺序固定。

这不代表所有桌面 UI 都会完整展示，也不意味着 MCP 存在统一的 1 MiB 输出上限。若宿主截断结果，应结合完整 CLI 审阅和来源文件再确认；不能把片段当作完整审阅。本版没有静默截断旧正文，也没有新增响应格式。

空项目来源错误码文案和竞品比较不在本版改动范围内。
